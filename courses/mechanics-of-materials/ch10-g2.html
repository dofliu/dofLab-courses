應變轉換計算工坊：機翼蒙皮與三角應變花

飛機機翼蒙皮在飛行中同時被拉、被壓、被剪。工程師在蒙皮上貼一組應變規，就能算出任意方向的應變、主應變與最大剪應變。這一關是公式計算工坊：用應變轉換方程式轉角度、用莫爾圓求 ε₁、ε₂、θp、γmax，再用0°/60°/120° 三角應變花反推全部應變，最後以廣義胡克定律回頭算出應力。

Phase 1 · 約 10 分鐘

計算前先備齊四個工具

任意方向的應變

εx′ = εavg + d·cos2θ + (γxy/2)·sin2θ

先算 εavg = (εx+εy)/2、d = (εx−εy)/2，再代入 2θ。剪應變部分：γx′y′/2 = −d·sin2θ + (γxy/2)·cos2θ。口訣：應力公式的 σ → ε、τ → γ/2。

主應變與最大剪應變

R = √(d² + (γxy/2)²)　γmax = 2R

圓心 εavg、半徑 R：ε₁,₂ = εavg ± R。方向 tan2θp = γxy/(εx−εy)。最容易錯的是 γmax = 2R，因為縱軸畫的是 γ/2。

0°/60°/120° 三角應變花

εx = ε0　εy = [2(ε60+ε120) − ε0]/3

三枚規、三個方向，解出三個未知數。剪應變 γxy = 2(ε60 − ε120)/√3。三枚規互成 60°，常用在不知道主方向的圓形區域。

平面應力的 εz 與 γabs

σz = 0 ⇒ εz = −ν(εx+εy)/(1−ν)

σz = 0 並不代表 εz = 0：板被拉長就會變薄。三個主應變 ε₁、ε₂、εz 都要比，γabs = εmax − εmin，有時比面內 γmax 還大。

互動實驗：轉動應變元素，看莫爾圓怎麼動

設定 εx、εy、γxy（伸長為正，單位 με = 10⁻⁶），再拖動 θ，左邊元素逆時針轉動，右邊莫爾圓上的深藍直徑轉 2θ。
