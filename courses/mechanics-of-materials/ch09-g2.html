應力轉換計算工坊：壓力容器焊縫與梁內一點的主應力

天然氣管線與鍋爐的螺旋焊管，焊縫是斜的——斜焊縫上到底承受多少正應力與剪應力？梁內某一點同時有彎曲與剪力，主應力又是多少？這一關是公式計算工坊：用薄壁壓力容器求出應力、用轉換方程式算任意斜面、用莫爾圓求 σ₁、σ₂、θp、τmax，還要分辨「面內」與「絕對」最大剪應力。

Phase 1 · 約 10 分鐘

計算前先備齊四個工具

薄壁壓力容器

σ環 = pr/t　σ縱 = pr/(2t)

像吹氣球：氣球先在「圓周方向」被撐裂，所以環向應力是縱向的兩倍。表面一點只受 σx = σ環、σy = σ縱，沒有剪應力（τxy = 0）。（適用 r/t ≥ 10）

斜面上的應力

σx′ = σavg + d·cos2θ + τxy·sin2θ

先算兩個固定組合 σavg = (σx+σy)/2、d = (σx−σy)/2，再代入 2θ。剪應力 τx′y′ = −d·sin2θ + τxy·cos2θ。壓力容器 τxy = 0，所以斜面上的剪應力只靠 d 與 sin2θ。

主應力與面內最大剪應力

R = √(d² + τxy²)，σ₁,₂ = σavg ± R

莫爾圓的圓心是 σavg、半徑是 R。圓與 σ 軸的兩個交點是主應力，最高點是面內最大剪應力 τmax = R，主方向 tan2θp = τxy / d。

面內 vs. 絕對最大剪應力

τabs = (σmax − σmin)/2

平面應力其實還有第三個主應力 σ₃ = 0。若 σ₁、σ₂ 異號，τabs = τmax（面內）；若同號，要把 0 算進去：τabs = σmax/2，會比面內的 R 還大！

互動實驗：轉動應力元素，看莫爾圓怎麼動

設定 σx、σy、τxy（拉為正、壓為負），再拖動 θ，左邊元素逆時針轉動，右邊莫爾圓上的深藍直徑轉 2θ。
