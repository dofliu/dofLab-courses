Phase 1 · 概念理解 · 10 分鐘

擰毛巾、鎖螺絲，都是在「扭轉」

雙手反向擰毛巾，毛巾上原本平行的條紋會變成螺旋線。圓軸受扭矩 T 時也一樣：每個橫截面繞軸心轉一個小角度，越遠的截面轉得越多，表面的小方格被「推歪」成平行四邊形，這就是剪應變 γ。

因為材料在線彈性範圍內 τ = Gγ，而 γ 從軸心 0 線性增加到外表面最大，所以剪應力也是中心為零、外表面最大。

本遊戲會用到的四條公式

τ = T·ρ / J
扭轉公式。ρ 為到軸心距離；ρ = c（外半徑）時 τ 最大：τmax = Tc/J
J = πc⁴ / 2
實心圓軸極慣性矩。空心軸：J = π(co⁴ − ci⁴)/2，單位 m⁴
φ = T·L / (J·G)
扭轉角（rad）。多段軸：φ = Σ TiLi/(JiGi)，內扭矩要逐段求
P = T·ω = 2πf·T
功率（W）。ω 單位 rad/s；轉速 n rpm → ω = 2πn/60

範例 1 · 汽車空心傳動軸

空心鋼軸的最大與最小剪應力

一輛後驅車的傳動軸為空心鋼管，外徑 80 mm、內徑 68 mm，引擎傳來扭矩 T = 1.5 kN·m。求管壁外表面與內表面的剪應力。

範例 2 · 齒輪箱階梯軸

兩段不同直徑的鋼軸，自由端轉了幾度？

鋼軸 A 端固定於牆面。B 處齒輪施加 TB = 500 N·m，自由端 C 施加 TC = 300 N·m（同方向）。AB 段直徑 50 mm、長 0.8 m；BC 段直徑 30 mm、長 0.6 m；G = 80 GPa。

拉動參數，看應力與扭轉角怎麼變
