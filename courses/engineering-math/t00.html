一階線性微分方程(I)：積分因子法

關卡 1 · 學習

RC 電路充電、物體在空氣中冷卻、水槽中鹽濃度的變化，這些現象都可以寫成「未知函數的一階導數加上它本身的某個倍數」。這類方程叫做一階線性微分方程，而積分因子法是解它最通用的工具。

定義 · 一階線性微分方程的標準式
$$\frac{dy}{dx} + P(x)\,y = Q(x)$$

其中 $P(x)$、$Q(x)$ 只與 $x$ 有關。$y$ 與 $y'$ 都只以一次方出現，而且不互乘，所以稱為「線性」。若 $Q(x)=0$，稱為齊次方程。

核心想法：把左邊湊成「乘積的導數」

找一個函數 $\mu(x)$ 乘在方程兩邊，使左邊剛好等於 $(\mu y)'$。由乘積律 $(\mu y)' = \mu y' + \mu' y$，比對 $\mu y' + \mu P y$ 可知需要 $\mu' = P\mu$，解得

$$\mu(x) = e^{\int P(x)\,dx}$$

這個 $\mu(x)$ 就是積分因子。積分常數可以省略，因為任何一個 $\mu$ 都能用。

核心公式 · 通解
$$\big(\mu y\big)' = \mu Q \quad\Longrightarrow\quad y(x) = \frac{1}{\mu(x)}\left[\int \mu(x)\,Q(x)\,dx + C\right]$$

解題四步驟

  1. 化成標準式：$y'$ 的係數必須是 1（有需要就整式除以 $y'$ 的係數）。
  2. 計算積分因子 $\mu = e^{\int P\,dx}$。
  3. 兩邊乘 $\mu$，寫成 $(\mu y)' = \mu Q$，兩邊積分，記得加 $C$。
  4. 除以 $\mu$ 得通解；若有初始條件，代入求 $C$。

互動圖：常係數情形 $y' + a\,y = Q$

此時 $\mu = e^{ax}$，解為 $y = \dfrac{Q}{a} + \left(y_0 - \dfrac{Q}{a}\right)e^{-ax}$。調整參數，觀察解如何趨近穩態值 $Q/a$；在 RC 電路中 $a = 1/(RC)$，$1/a$ 就是時間常數 $\tau$。

解曲線 $y(x)$ 穩態值 $Q/a$ 時間常數 $x = 1/a$

關卡 2 · 理解

兩個例題由淺入深。先自己試著做，再展開步驟對照。

例題 1 · 基礎（常係數）

求 $\dfrac{dy}{dx} + 2y = 4$ 的通解。

1
已是標準式，$P(x) = 2$，$Q(x) = 4$。
2
積分因子：$\mu = e^{\int 2\,dx} = e^{2x}$。
3
兩邊乘 $e^{2x}$：$$e^{2x}y' + 2e^{2x}y = 4e^{2x} \;\Longrightarrow\; \big(e^{2x}y\big)' = 4e^{2x}$$
4
兩邊積分：$e^{2x}y = 2e^{2x} + C$。
5
除以 $e^{2x}$：$$\boxed{\,y = 2 + Ce^{-2x}\,}$$ 當 $x\to\infty$ 時 $y\to 2$，正是穩態值 $Q/a = 4/2$。
例題 2 · 進階（變係數＋初始條件）

解初值問題 $x\,y' + 2y = x^2$，$y(1) = 1$，其中 $x > 0$。

1
$y'$ 的係數不是 1，先除以 $x$：$$y' + \frac{2}{x}\,y = x,\qquad P(x) = \frac{2}{x},\; Q(x) = x$$
2
積分因子：$\mu = e^{\int \frac{2}{x}dx} = e^{2\ln x} = x^2$（因 $x>0$，不需絕對值）。
3
兩邊乘 $x^2$：$\big(x^2 y\big)' = x^3$。
4
積分：$x^2 y = \dfrac{x^4}{4} + C$，所以 $y = \dfrac{x^2}{4} + \dfrac{C}{x^2}$。
5
代入 $y(1) = 1$：$\dfrac14 + C = 1$，得 $C = \dfrac34$。$$\boxed{\,y = \frac{x^2}{4} + \frac{3}{4x^2}\,}$$
✓
驗算：$y' = \dfrac{x}{2} - \dfrac{3}{2x^3}$，$xy' + 2y = \dfrac{x^2}{2} - \dfrac{3}{2x^2} + \dfrac{x^2}{2} + \dfrac{3}{2x^2} = x^2$。正確。
至少展開 1 個例題的步驟後即可前往。

RC 電路接上衰減電源

串聯 RC 電路中 $R = 5\,\text{k}\Omega$、$C = 100\,\mu\text{F}$，電容一開始不帶電，即 $v_C(0) = 0$。在 $t = 0$ 時接上一顆逐漸耗盡的電源 $E(t) = 12e^{-t}\ \text{V}$（$t$ 以秒計）。

(a) 求電容電壓 $v_C(t)$。
(b) 電容電壓的最大值是多少伏特？發生在何時？

完整解答

1
KVL：$Ri + v_C = E(t)$，且 $i = C\,\dfrac{dv_C}{dt}$，得 $RC\,v_C' + v_C = E(t)$。$RC = 5000 \times 100\times10^{-6} = 0.5\ \text{s}$，所以 $$v_C' + 2v_C = 24e^{-t}$$
2
積分因子 $\mu = e^{\int 2\,dt} = e^{2t}$，乘上後：$\big(e^{2t}v_C\big)' = 24e^{t}$。
3
積分：$e^{2t}v_C = 24e^{t} + K$，即 $v_C = 24e^{-t} + Ke^{-2t}$。代入 $v_C(0) = 0$ 得 $K = -24$：$$\boxed{\,v_C(t) = 24\left(e^{-t} - e^{-2t}\right)\ \text{V}\,}$$
4
求極值：$v_C'(t) = 24\left(-e^{-t} + 2e^{-2t}\right) = 0 \Rightarrow e^{-t} = \dfrac12 \Rightarrow t = \ln 2 \approx 0.693\ \text{s}$。
5
$v_{C,\max} = 24\left(\dfrac12 - \dfrac14\right) = \boxed{6\ \text{V}}$。此後電源持續衰減，電容經電阻放電，$v_C\to 0$。
