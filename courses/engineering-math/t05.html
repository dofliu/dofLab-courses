二階非齊次微分方程(I)：未定係數法

Method of Undetermined Coefficients · 單元 06 / 30
Level 1 · Learn

📚 先猜形式，再定係數

常係數二階非齊次線性微分方程的一般形式為

$$y'' + a\,y' + b\,y = g(x)$$

其中 $a,b$ 為常數，$g(x)\neq 0$ 稱為強制項（forcing term）。在工程上，$g(x)$ 就是外加的電壓、外力或熱源。

定理｜通解結構

非齊次方程的通解 = 對應齊次方程的通解 + 任一個特解：

$$y(x) = y_h(x) + y_p(x), \qquad y_h = c_1y_1 + c_2y_2$$

$y_h$ 由特徵方程 $r^2 + ar + b = 0$ 求得（上一單元的內容）；$y_p$ 則是本單元的重點。

未定係數法的想法：當 $g(x)$ 是多項式、指數函數、正弦餘弦，或它們的乘積時，這些函數微分後「形式不變」。因此可以先猜 $y_p$ 與 $g(x)$ 同一家族、係數未知，代回方程比較係數，解出係數即可。

強制項 $g(x)$特解試探形式 $y_p$
常數 $k$$A$
$n$ 次多項式 $P_n(x)$$A_nx^n + \cdots + A_1x + A_0$
$k\,e^{\alpha x}$$A\,e^{\alpha x}$
$k\cos\beta x$ 或 $k\sin\beta x$$A\cos\beta x + B\sin\beta x$
$P_n(x)\,e^{\alpha x}$$(A_nx^n+\cdots+A_0)\,e^{\alpha x}$
$e^{\alpha x}\cos\beta x$ 或 $e^{\alpha x}\sin\beta x$$e^{\alpha x}(A\cos\beta x + B\sin\beta x)$
修正規則（Modification Rule）⚠️ 最常考

若試探形式中的某一項已經是齊次解，代入後會得到 $0$，無法匹配 $g(x)$。此時把整個試探式乘上 $x^s$，$s$ 取最小的正整數使得沒有任何一項與 $y_h$ 重複（二階方程 $s$ 為 1 或 2）。

例：$y''-y=e^{x}$，齊次解含 $e^{x}$，故改猜 $y_p = Ax\,e^{x}$。

解題四步驟

① 解特徵方程得 $y_h$　② 依 $g(x)$ 查表寫出 $y_p$，檢查修正規則　③ 代入方程、比較同類項係數　④ 寫出 $y = y_h + y_p$，若有初始條件最後再求 $c_1, c_2$。

互動實驗：強迫振動的穩態特解

考慮 $y'' + c\,y' + k\,y = \cos\omega t$。以 $y_p = A\cos\omega t + B\sin\omega t$ 代入可得

$$A=\frac{k-\omega^2}{(k-\omega^2)^2+(c\omega)^2},\qquad B=\frac{c\,\omega}{(k-\omega^2)^2+(c\omega)^2}$$

拖動滑桿觀察：當 $\omega$ 接近 $\sqrt{k}$ 且阻尼 $c$ 很小時，特解振幅會急遽放大（共振）。

強制項 $\cos\omega t$ 特解 $y_p(t)$

🔍 例題演練

例題 1 · 基礎：多項式強制項

求 $y'' - 3y' + 2y = 4x^2$ 的通解。

1
齊次解

特徵方程 $r^2-3r+2=(r-1)(r-2)=0$，得 $r=1,2$。

$$y_h = c_1e^{x}+c_2e^{2x}$$
2
寫出試探形式

$g(x)=4x^2$ 為二次多項式，且 $0$ 不是特徵根，不需修正：

$$y_p = Ax^2+Bx+C,\quad y_p' = 2Ax+B,\quad y_p''=2A$$
3
代入並整理$$2A-3(2Ax+B)+2(Ax^2+Bx+C) = 2A\,x^2+(2B-6A)\,x+(2A-3B+2C)$$
4
比較係數$$\begin{cases}2A=4\\ 2B-6A=0\\ 2A-3B+2C=0\end{cases}\Rightarrow A=2,\;B=6,\;C=7$$
5
通解$$y = c_1e^{x}+c_2e^{2x}+2x^2+6x+7$$

驗算：$y_p''=4$，$-3y_p'=-12x-18$，$2y_p=4x^2+12x+14$，相加得 $4x^2$ ✓

例題 2 · 進階：需要修正規則

求 $y'' - y' - 2y = 3e^{2x}$ 的通解。

1
齊次解

$r^2-r-2=(r-2)(r+1)=0$，得 $r=2,-1$。

$$y_h=c_1e^{2x}+c_2e^{-x}$$
2
檢查重複

依表應猜 $Ae^{2x}$，但 $e^{2x}$ 已是齊次解（$r=2$ 為單根），代入會得 $0$。依修正規則乘上 $x$：

$$y_p = Ax\,e^{2x}$$
3
求導$$y_p' = A e^{2x}(1+2x),\qquad y_p''=Ae^{2x}(4+4x)$$
4
代入$$Ae^{2x}\big[(4+4x)-(1+2x)-2x\big] = 3A\,e^{2x} = 3e^{2x}\;\Rightarrow\; A=1$$

注意 $x$ 項會自動相消，這正是修正規則有效的原因。

5
通解$$y = c_1e^{2x}+c_2e^{-x}+x\,e^{2x}$$

🏆 挑戰關：彈簧－阻尼系統的強迫振動

一台精密量測平台可視為質量－彈簧－阻尼系統：質量 $m=1\ \text{kg}$、阻尼係數 $c=2\ \text{N·s/m}$、彈簧常數 $k=5\ \text{N/m}$。馬達的不平衡轉子施加外力 $F(t)=10\cos t\ \text{N}$。平台初始靜止於平衡點：$x(0)=0,\;x'(0)=0$。

$$x'' + 2x' + 5x = 10\cos t$$

(a) 求位移 $x(t)$。
(b) 經過長時間後，平台的穩態振幅是多少公尺？（取到小數點後 2 位）

m
1
齊次解

$r^2+2r+5=0\Rightarrow r=-1\pm 2i$（欠阻尼）

$$x_h = e^{-t}(c_1\cos 2t + c_2\sin 2t)$$
2
試探特解

$\pm i$ 不是特徵根，不需修正：$x_p = A\cos t + B\sin t$

$$x_p'' + 2x_p' + 5x_p = (4A+2B)\cos t + (4B-2A)\sin t$$
3
比較係數$$\begin{cases}4A+2B=10\\ -2A+4B=0\end{cases}\Rightarrow A=2,\;B=1,\qquad x_p = 2\cos t+\sin t$$
4
代入初始條件$$x(0)=c_1+2=0\Rightarrow c_1=-2$$$$x'(0) = -c_1+2c_2+1 = 0\Rightarrow c_2=-\tfrac32$$
5
完整解$$x(t) = e^{-t}\!\left(-2\cos 2t-\tfrac32\sin 2t\right) + 2\cos t+\sin t$$

暫態項因 $e^{-t}$ 迅速衰減，剩下穩態響應 $x_p$，振幅 $\sqrt{A^2+B^2}=\sqrt{5}\approx 2.24\ \text{m}$。
